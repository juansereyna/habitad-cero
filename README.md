# Hábitat Cero · sitio web

Página de inicio de Hábitat Cero: diseño y acabados para apartamentos, casas, locales y oficinas en obra gris en Bogotá y la Sabana.

- `index.html`: la página completa (HTML y CSS en un solo archivo, sin dependencias).
- `img/`: fotos de referencia. Son imágenes generadas con IA (obra gris + boceto); se reemplazan por fotos reales de obras propias.

## Publicación

El sitio se publica con GitHub Pages desde la rama `main`, carpeta raíz. Cada cambio que se sube a `main` queda en línea en uno o dos minutos.

## Pendientes antes de lanzar

- Reemplazar los textos entre corchetes: `[WHATSAPP]`, `[CORREO]`, `[ALIADO FINANCIERO]`, condiciones de devolución y garantía.
- Conectar el formulario de cotización (hoy es una muestra y no envía datos).
- Fotos reales de obras propias.
- Dominio propio (opcional), por ejemplo `habitatcero.co`.
